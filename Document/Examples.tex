\chapter{Examples}

All examples has been tested on Ubuntu 22.04.5 LTS. Before running the examples, please enter the directory:
\begin{lstlisting}[breaklines=true]
cd Examples
\end{lstlisting}

In all the examples, the alias \lstinline{jem} is used to enable \lstinline{jemalloc}:
\begin{lstlisting}[breaklines=true]
alias jem='LD_PRELOAD=/usr/lib/x86_64-linux-gnu/libjemalloc.so.2'
\end{lstlisting}

In order to obtain higher runtime efficiency, it is recommended to enable transparent huge page by:
\begin{lstlisting}[breaklines=true]
echo always | sudo tee /sys/kernel/mm/transparent_hugepage/enabled
\end{lstlisting}

\section{Examples with domain decomposition}

\begin{enumerate}[label=$\blacksquare$]
\item TestBeam, on a machine with two AMD EPYC 7742 and 512GB DDR4 RAM.
  \begin{enumerate}[label=$\bullet$]
  \item Without \lstinline{jemalloc} and without nested parallelism:
\begin{lstlisting}[breaklines=true]
./TestBeam
\end{lstlisting}
  \item With \lstinline{jemalloc} and without nested parallelism:
\begin{lstlisting}[breaklines=true]
jem ./TestBeam
\end{lstlisting}
  \item With \lstinline{jemalloc} and with nested parallelism:
\begin{lstlisting}[breaklines=true]
jem ./TestBeam 128 4 2
\end{lstlisting}
\lstinline{128} is the number of total CPU cores, \lstinline{4} is the number of threads for per subdomain, and \lstinline{2} is the number of threads for per interface. The time cost with nested parallelism will be about half of that without nested parallelism.
  \item The default number of subdomains is 32 by \lstinline|domaNumb = {16, 2, 1};|. By \lstinline|domaNumb = {32, 4, 1};|, the number of subdomains is 128.
\begin{lstlisting}[breaklines=true]
jem ./TestBeam 128 1 1
\end{lstlisting}
The time cost of setting \lstinline|128 1 1| is just a little bit lower than that of \lstinline|128 4 1|: for AMD EPYC 7742, \lstinline{4} CPU cores share the same 16MB L3 cache. The time cost of setting \lstinline|64 1 1| is about twice that of \lstinline|128 1 1|.
  \item If there is not enough RAM (for example, less than 32GB), please use \lstinline|Ddpca::I64 globLeve = 1;|.
  \item If there is not enough CPU cores (for example, less than 32 CPU cores), please do not use nested parallelism.
  \end{enumerate}
\item TestBlock, on a machine with two AMD EPYC 7742 and 512GB DDR4 RAM.
\begin{lstlisting}[breaklines=true]
jem ./TestBeam 128 4 2
\end{lstlisting}
\item TestCylinder, on a machine with two AMD EPYC 7742 and 512GB DDR4 RAM.
\begin{lstlisting}[breaklines=true]
jem ./TestBeam 128 2 1
\end{lstlisting}
\item TestDehw, on a machine with two AMD EPYC 7742 and 512GB DDR4 RAM.
\begin{lstlisting}[breaklines=true]
jem ./TestBeam 128 2 1
\end{lstlisting}
\item TestPureTorsion, on a machine with two AMD EPYC 7742 and 512GB DDR4 RAM.
\begin{lstlisting}[breaklines=true]
jem ./TestBeam 128 4 2
\end{lstlisting}
\end{enumerate}
